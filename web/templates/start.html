Как подключить гильдию, привязать игровой аккаунт и настроить уведомления. Команды Discord — на странице Документация.

0. Гильдия ещё не подключена к боту?

Подключение платное — 1000 ₽/мес или 10000 ₽/год за гильдию (разовый платёж, не автосписание). Сделать это может любой офицер гильдии:

  1. Если будете пользоваться Discord, пригласите бота на сервер гильдии — {% if public_discord_invite_url() %}добавить Дроидца{% else %}командой /пригласить{% endif %}. Если боту не хватит прав, он сам напишет каких.
  2. Подайте заявку и оплатите на странице Подписка (вход через Discord): код союзника любого участника и, если нужен Discord, ID сервера. Для гильдии, которая пользуется только Telegram, ID сервера не нужен. Команда /подписка на сервере гильдии даёт ссылку, где ID сервера уже подставлен. Бот проверит код через игру и даст ссылку на оплату.
  3. Доступ включится автоматически в течение минуты после оплаты — дальнейшие шаги ниже.

За 7 дней до окончания офицеры и лидер видят на сайте напоминание с кнопкой «Продлить». Если подписка уже закончилась (доступ отключается автоматически), после входа на сайт офицер увидит окно «Подписка закончилась» с ценами — после оплаты гильдия включится со всеми прежними настройками, регистрациями и историей. Условия — на странице оферты.

1. Привяжите себя к коду союзника

В Discord выполните /регистрация и укажите свой код союзника — на сервере гильдии или в личных сообщениях боту. В Telegram используйте /reg 123456789, заменив пример своим кодом.

Без этого шага команды вида «мой персонаж» (например /статы без указания игрока) не смогут определить ваш игровой аккаунт. Регистрация также нужна, чтобы сайт определил вашу гильдию и права доступа.

Отвязать свой игровой аккаунт в Discord — /регистрация_отмена. Если у вас несколько аккаунтов (основной + альт), команда попросит уточнить, какой из них отвязать.

2. Узнайте свой уровень доступа

Доступ определяется игровым рангом в гильдии (данные из самой игры):

  • Офицер / лидер — доступны управление гильдией и офицерские команды выбранной версии бота.
  • Участник гильдии — доступны личные команды, «Мой профиль» и инструменты для участников (см. ниже).

Изменение ранга в игре учитывается автоматически при обновлении данных. Сразу после повышения новые права могут появиться с задержкой.

4. Обычный участник — что доступно

На сайте после входа — Мой профиль: проверка своих статов по плейтам и датакронов по требованиям сезона, свои задачи, готовые к установке омикроны, потраченные ресурсы и привязка альт-аккаунтов.

Также доступны калькулятор Завоевания и, если он включён для гильдии, калькулятор модулей. В калькуляторе модулей участник может применять пресеты гильдии; сохранять и удалять их могут офицеры.

В Discord — проверка своего аккаунта:

  • /статы — проверка своих статов по нормам гильдии, с прогнозом на нужный релик.
  • /статы_требования плейты и /статы_требования список — требования гильдии к персонажам.
  • /дк_требования проверить и /дк_требования список — проверка своих датакронов по нормам гильдии.
  • /омикроны отчёт — какие приоритетные омикроны вы уже готовы поставить.
  • /задачи отчёт — прогресс по своим заданиям на прокачку.
  • /регистрация_отмена — отвязать себя, если понадобится.

5. Бот есть и в Telegram

Discord-бот, Telegram-бот и сайт используют общие данные гильдии. Чтобы пользоваться своим аккаунтом на обеих платформах, свяжите Discord и Telegram через «Мой профиль». Если часть гильдии пользуется Telegram — гильдию подключать отдельно не нужно, достаточно уже пройденного шага 0 выше.

  • Личные команды — профиль, статы, датакроны, задачи и т.д. — доступны в личных сообщениях бота: откройте {% if public_telegram_bot_username() %} @{{ public_telegram_bot_username() }} {% else %} бота в Telegram {% endif %} и нажмите «Старт». Если игровой аккаунт ещё не привязан, выполните /reg 123456789, указав свой код союзника. Список команд — /help.
  • Чат гильдии — офицер привязывает групповой чат командой /bind прямо в этом чате, после чего там же командой /notify включаются оповещения гильдии (энка, задачи, омикроны) — так же, как каналы в Discord.
  • Один и тот же игрок в обоих ботах — если вы уже зарегистрированы в Discord, привяжите Telegram кнопкой «📱 Привязать Telegram» в Моём профиле на сайте и завершите привязку в Telegram. Так оба бота будут использовать вашу общую регистрацию.
