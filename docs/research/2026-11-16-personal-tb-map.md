# Интерактивная личная карта ТБ

Игроку тяжело ориентироваться в строках и обозначениях. Запрос относится к экрану «Мой профиль» → «ТБ» → «Моя карта ТБ». [Сообщение игрока](https://discord.com/channels/931280548402442310/1153765810439987280/1571780757003960381).

## Где теряется ориентация

Планеты уже можно выбирать на сетке этапов. При выборе планеты страница прокручивается к панели, где миссии представлены сначала строкой ссылок, затем списком раскрывающихся карточек. Например, «⚔ Бой · c1» и «⚔ Бой · c2» отличаются только коротким кодом. `⚔` означает наземный бой, `◈` — бой флота, `★` — спецмиссию, `✎` рядом с миссией — сохранённую памятку. В ссылке «✎ Планета» тот же карандаш ведёт в общую памятку, даже если она пуста. [Шаблон карты](../../web/templates/tb_map.html#L14), [навигация](../../web/static/tb_map.js#L15).

На этой же вкладке есть «Мой ВИ». Он показывает назначения во взводы и готовность игрока по этапам активного ордера. «Моя карта ТБ» использует каталог «Восхода Империи» и открывается независимо от ордера. [Карточка игрока](../../web/templates/player_card.html#L420), [расчёт «Мой ВИ»](../../services/tb_my.py#L110), [маршрут карты](../../web/routes/tb_map.py#L22).

## Какие данные есть для схемы

- Этапы и три ветки планет определены в `tb_projection`. Зеффо и Мандалор привязаны к этапам 3 и 4. Этого достаточно, чтобы показать общий маршрут из шести этапов с отдельными ветками и бонусными узлами. [Структура планет](../../services/tb_projection.py#L18).
- Публичный каталог на 16 ноября возвращает 20 планет и 98 боёв, флотских боёв и спецмиссий. У каждой из этих миссий есть `position` со значением `left` или `right`, координат `x/y` в каталоге нет. У Мустафара четыре наземных боя и флот имеют `right`, поэтому по этому полю можно определить сторону схемы, а расположение нескольких узлов внутри стороны потребуется задать самостоятельно. Текущий импорт поле `position` отбрасывает. [Ответ API](https://swgoh.ru/api/tbmap), [импорт каталога](../../services/tb_squads.py#L46).
- Коды `c1`, `c2` и т. п. принадлежат каталогу. Они нужны для доступа к сохранённым записям, поскольку ключ памятки включает пользователя, планету и код миссии. Пользовательский номер боя следует подписывать как номер на схеме сайта, если его показывают. Сопоставление с игровым номером или с номером в «Мой ВИ» по одному `cN` не подтверждено. [Описание источника](../../services/tb_squads.py#L1), [хранение памяток](../../services/tb_personal.py#L9), [номера в «Мой ВИ»](../../web/templates/_player_tb.html#L26).

## Вариант интерфейса

Игрок прислал два ориентира. У Genskaar зоны расположены на фоне карты, а наведение или касание открывает сведения. У того же автора есть отдельная карта «Восхода Империи». Её CSS задаёт координаты **планет** на общем фоне, поэтому по ней можно сверить компоновку верхнего уровня. SWGoH.ru показывает планеты по фазам и отдельные сведения по планете, включая типы миссий и противников. Для личной карты подходит пространственная навигация Genskaar с русскими подписями и раскрытием выбранной миссии внутри планеты. [Джеонозис](https://genskaar.github.io/tb_geo/html/ls.html), [карта ВИ Genskaar](https://genskaar.github.io/tb_empire/html/main.html), [координаты планет](https://genskaar.github.io/tb_empire/css/main.css), [SWGoH.ru](https://swgoh.ru/tb), [Мустафар](https://swgoh.ru/tb/planet/mustafar).

1. На общей карте показать ветки по постоянным дорожкам через шесть этапов, а бонусные планеты — отдельными узлами рядом со своим этапом. На телефоне показать выбранный этап с переключением соседних этапов. Выделить открытую планету.
2. Внутри планеты заменить дублирующиеся список и строку ссылок одной схемой с нажимаемыми узлами. Например, «Наземный бой», «Бой флота», «Спецмиссия». Если на планете несколько одинаковых боёв, различать их расположением и номером на схеме. Если есть краткая отличительная деталь из каталога, вывести её рядом, например обязательного персонажа. Тип и отметку «Есть памятка» показать текстом. Оставить «Памятку по планете» самостоятельной кнопкой. При нажатии открыть условия, противников, готовые отряды и личную памятку выбранной миссии под схемой.
3. Для первой версии достаточно схематичного расположения. Импорт `position` даст признак стороны, а миссии без этого поля в старом кэше или архиве можно открыть из обычного перечня. Для повторения расположения кнопок из игры понадобится отдельная сверка с игровым экраном, поскольку API не даёт точных координат. При переходе между узлами текущую несохранённую правку следует удерживать в форме либо явно подтверждать её сброс.

Эту схему можно добавить в существующий маршрут `/tb/map`, пользуясь текущими формами, библиотекой гильдии и ключами памяток. `GET`, `POST` и якоря уже поддерживают возврат к выбранной миссии. На 16 ноября восемь локальных тестов карты прошли. Они проверяют сохранение, удаление, архивные миссии, доступ и переходы во встроенной карте. Визуальная проверка авторизованной страницы в исследование не входила. [Маршруты и якоря](../../web/routes/tb_map.py#L46), [тесты](../../tests/test_tb_personal_map.py).
